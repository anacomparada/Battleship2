🎯 Project overview

This project serves as a template and reference for students learning Object-Oriented Programming (OOP) and Software Quality. It simulates a battleship environment where players must strategically place ships and sink the enemy fleet.


The rules

The game is played on a 10×10 grid. Hits are calculated based on the intersection of the shot vector and the ship's bounding box. Each player places their fleet and takes turns firing at coordinates.

🚀 Installation & setup

Prerequisites

JDK 21+ Git Docker (optional)
  1. Clone the repository 
    git clone https://github.com/anacomparada/Battleship2.git
  2. Navigate to directory 
    cd Battleship2
  3. Build and run with Maven 
    mvn clean package
java -jar target/BattleshipGamePlayer-2.0.jar
  4. Or run with Docker 
    docker pull anacomparada/battleship-game:latest
docker run -it anacomparada/battleship-game:latest
